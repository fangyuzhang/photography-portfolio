# 摄影作品集 · 35 张

日常拍摄的随手集，题材以**花卉特写**为主，另有**城市街头**与**古建细节**。
整组用同一台机身、两只镜头完成，参数不做后期抹除，可逐张查看。

**在线展厅**：https://fangyuzhang.github.io/photography-portfolio/

---

## 器材与拍摄习惯

| 项 | 情况 |
|---|---|
| 机身 | Nikon APS-C，2400 万像素 |
| 主力镜头 | 50mm f/1.8（等效 75mm），占全部照片 65% |
| 副镜 | 28–200mm（等效 42–300mm），长焦段占 27% |
| 光圈 | f/1.8 – f/5.6，几乎不用更小光圈 |
| 感光度 | 全部 ISO 100，不用自动 ISO |
| 快门 | 1/200–1/3200 为主，仅 1 张慢于 1/100 |
| 模式 | M 档约六成、A 档约四成；M 档用中央重点测光，A 档用点测光 |
| 曝光补偿 | 全组 0 EV |

**取舍逻辑**：等效 75mm 比标头略紧，又不像长焦那样把主体从环境里剥离；
一半照片把光圈开到 f/1.8–2.5 让背景退进失焦，另一半收在 f/4 左右保细节。
宁可把快门推到 1/1000 以上，也不动 ISO——这是我在这组里最固定的一条底线。
